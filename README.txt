UPPER / LOWER 3.1 PWA

1. Išarchyvuok ZIP.
2. Įkelk VISĄ aplanką į HTTPS statinio hostingo paslaugą (pvz. Netlify Drop, Cloudflare Pages, GitHub Pages).
3. Telefone atidaryk gautą HTTPS adresą su Chrome.
4. Chrome meniu pasirink „Įdiegti programą“ arba „Pridėti prie pagrindinio ekrano“.
5. Duomenys saugomi lokaliai to paties HTTPS adreso naršyklės saugykloje (localStorage). Reguliariai naudok Nustatymai > Eksportuoti JSON.
6. Nustatymai > Atkurti iš JSON leidžia perkelti duomenis į kitą įrenginį.

Vien tik atidarius index.html iš failų sistemos PWA įdiegimas ir offline režimas nėra garantuojami. Reikalingas HTTPS arba localhost.
